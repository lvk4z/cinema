Deploy on GitHub Pages — Free

⚠ HTTPS is required. PeerJS WebRTC won't work on file:// — it only works when served over HTTP(S). GitHub Pages gives you a free HTTPS URL in ~60 seconds.

1
Create a GitHub account

Go to github.com → Sign up (free).

2
New public repository

Click + → New repository. Name it e.g. cinemasync. Set to Public. Click Create repository.

3
Upload file as index.html

On the repo page click uploading an existing file. Drag the file in. Rename it to index.html. Click Commit changes.

4
Enable GitHub Pages

Go to Settings → Pages. Under Branch select main and / (root), click Save.

5
Done — share your URL

Your app is live at https://YOUR-USERNAME.github.io/cinemasync/. Open it, copy the invite link, send to her. ♥

★
How sync works

The app sends postMessage commands directly to the VidFast player (pause/play/seek). Both players receive the same command at the same time via PeerJS P2P. Clicking on the video no longer redirects anywhere — the iframe runs in a sandbox that blocks popups and page navigations from ad scripts.
