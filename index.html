Deploy on GitHub Pages — Free

⚠ HTTPS required — PeerJS WebRTC breaks on file://. GitHub Pages gives you free HTTPS in ~60 s.

1
Create GitHub account

github.com → Sign up (free).

2
New public repository

Click + → New repository. Name e.g. cinemasync. Set Public. Create.

3
Upload file as index.html

On repo page → uploading an existing file. Drag file. Rename to index.html. Commit.

4
Enable Pages

Settings → Pages. Branch: main, / (root). Save.

5
Share URL ♥

Live at https://USERNAME.github.io/cinemasync/. Open, Copy invite link, send her.

★
Jak synchronizować

🎬 3-2-1 Go! — obie strony dostają odliczanie, a po 0 każde z was klika Play jednocześnie. Albo ⏸/▶ po prostu synchronizuje pauzę. Skróty klawiaturowe działają gdy focus jest poza playerem (kliknij na syncbar).
