Deploy on GitHub Pages — Free

⚠ You must serve this file over HTTPS — PeerJS WebRTC and the stream extractor both require it. Opening the file as file:// causes the PeerJS error you saw. GitHub Pages gives you HTTPS automatically at no cost.

1
Create a GitHub account

Go to github.com → Sign up (free).

2
Create a new public repository

Click + → New repository. Give it any name, e.g. cinemasync. Select Public. Click Create repository.

3
Upload the HTML file as index.html

On the repo page click uploading an existing file. Drag the downloaded cinemasync.html in. Rename it to index.html in the filename field. Click Commit changes.

4
Enable GitHub Pages

Go to Settings → Pages. Under Build and deployment → Branch, select main and / (root), click Save.

5
Your app is live in ~60 seconds

URL: https://YOUR-USERNAME.github.io/cinemasync/
Open it, click Copy invite link, send it to her. Done ♥

★
How sync works

The app tries to extract the direct video stream URL from the page. If it succeeds → native <video> element with automatic real-time sync (pause, play, seek all propagate instantly). If the extraction fails due to CORS or obfuscation → iframe fallback with signal-based sync (buttons send "pause now" / "play now" prompts to your partner).
