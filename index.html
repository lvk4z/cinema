Deploy on GitHub Pages — Free

⚠ HTTPS required. PeerJS WebRTC won't work on file://. GitHub Pages gives you a free HTTPS URL in ~60 seconds.

1
Create a GitHub account

Go to github.com → Sign up (free).

2
New public repository

Click + → New repository. Name it e.g. cinemasync. Set to Public. Click Create repository.

3
Upload as index.html

On repo page click uploading an existing file. Drag the file in. Rename to index.html. Commit changes.

4
Enable GitHub Pages

Settings → Pages. Branch: main, folder / (root). Save.

5
Done ♥

Live at https://YOUR-USERNAME.github.io/cinemasync/. Open, copy invite link, send her.

Jak działa sync

Przyciski ⏸/▶/⟳ wysyłają postMessage do playera VidFast (obsługuje API) i jednocześnie przez PeerJS P2P do partnerki. Brak sandbox — zamiast tego dwie przezroczyste nakładki blokują pierwszy klik i górny pasek reklamowy, gdzie zazwyczaj siedzą overlay'e przekierowujące.
