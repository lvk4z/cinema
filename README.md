# Biblioteka Oli ❤️

Statyczny czytnik ebooków przygotowany pod GitHub Pages i wygodne czytanie na tablecie/iPadzie.

## Funkcje

- domyślna książka: `Buszujący w zbożu`, ładowana z pliku tekstowego,
- automatyczny spis 25 rozdziałów z linkami w bocznym menu,
- zapamiętywanie książki, ostatniej strony i ustawień w przeglądarce,
- tryb normalny oraz delikatny tryb miłosny dla Oli,
- ciemny design z regulacją rozmiaru czcionki, kroju i jasności,
- timer czytania,
- przycisk pełnego ekranu,
- import plików `.txt` i `.md` bez backendu.

## Publikacja na GitHub Pages

1. Wgraj pliki repozytorium na GitHuba.
2. Wejdź w `Settings` -> `Pages`.
3. Wybierz `Deploy from a branch`.
4. Ustaw branch `main` i folder `/root`.
5. Po chwili strona będzie dostępna pod adresem GitHub Pages.

## Ksiazka

Plik `document.pdf` został dostarczony lokalnie jako legalny egzemplarz, a tekst dla czytnika został wyciągnięty do `books/buszujacy-w-zbozu.txt`. Przed publikacją na publicznym GitHub Pages upewnij się, że masz prawo udostępniać treść książki publicznie.

Czytnik nadal pozwala wgrać własny legalnie posiadany plik tekstowy lokalnie w przeglądarce. Własny plik i postęp czytania zostaną zapamiętane tylko na danym urządzeniu.
